# 部署

***

Flowise 采用与平台无关的架构设计，确保与各种部署环境兼容，以满足您的基础设施需求。

## 本地机器

要在本地部署 Flowise，请按照我们的[开始](../../getting-started/)指南进行操作。

## 现代云提供商

现代云平台优先考虑自动化并专注于开发人员工作流程，简化云管理和持续维护。 

这减少了所需的技术专业知识，但可能会限制您对底层基础设施的定制级别。

* [Elesio](https://elest.io/open-source/flowiseai)
* [拥抱脸](hugging-face.md)
* [北翼](https://northflank.com/stacks/deploy-flowiseai)
* [铁路](railway.md)
* [渲染](render.md)
* [复制](replit.md)
* [RepoCloud](https://repocloud.io/details/?app\_id=29)
* [Sealos](sealos.md)
* [Zeabur](zeabur.md)

## 成熟的云提供商

另一方面，成熟的云提供商需要更高水平的技术专业知识来管理和优化您的特定需求。 

然而，这种复杂性也为您的云环境提供了更大的灵活性和控制力。

* [AWS](aws.md)
* [Azure](azure.md)
* [DigitalOcean](digital-ocean.md)
* [GCP](gcp.md)
* [使用 Helm 的 Kubernetes](https://artifacthub.io/packages/helm/cowboysysop/flowise)

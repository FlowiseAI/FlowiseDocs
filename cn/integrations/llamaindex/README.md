# 骆驼指数

***

[LlamaIndex](https://www.llamaindex.ai/) 是一个数据框架，供 LLM 应用程序摄取、构建和访问私有或特定于域的数据。它具有用于设计 RAG（检索增强生成）应用程序的高级检索技术。

Flowise 通过提供可视化界面来补充 LlamaIndex。在这里，节点被组织成不同的部分，从而更容易构建工作流程。

### LlamaIndex 部分：

* [代理](agents/)
* [聊天模型](chat-models/)
* [嵌入](embeddings/)
* [引擎](engine/)
* [响应合成器](response-synthesizer/)
* [工具](tools/)
* [向量存储](vector-stores/)

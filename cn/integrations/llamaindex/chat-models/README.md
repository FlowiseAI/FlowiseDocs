# 聊天模型

***

聊天模型将消息列表作为输入，并返回模型生成的消息作为输出。这些模型（例如 **gpt-3.5-turbo** 或 **gpt4**）比其前身 Completions 模型（例如 **text-davincii-003**）功能强大且便宜。

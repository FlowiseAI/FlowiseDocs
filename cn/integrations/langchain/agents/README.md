# 代理

***

语言模型本身无法采取行动——它们只是输出文本。

代理是使用 LLM 作为推理引擎来确定要采取哪些操作以及这些操作的输入应该是什么的系统。然后，这些操作的结果可以反馈给代理，并确定是否需要更多操作，或者是否可以完成。

# 对话摘要记忆

使用 Flowise 数据库表 `chat_message` 作为存储/检索对话的存储机制。

这种记忆类型会随着时间的推移创建对话的简短摘要。这对于缩短长时间讨论中的信息很有用。随着对话的进行，它会更新并保存当前摘要。这在较长的聊天中特别有用，因为保存过去的每条消息会占用太多空间。

## 输入

|参数|描述 |默认|

|聊天模型| LLM 用于执行汇总 |               |
|会话 ID |用于检索/存储消息的 ID。如果未指定，将使用随机 ID。 |               |

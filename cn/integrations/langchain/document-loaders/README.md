# 文档加载器

***

文档加载器允许您加载来自不同来源的文档，例如 PDF、TXT、CSV、Notion、Confluence 等。它们通常与 [向量存储](../vector-stores/) 一起使用，以作为嵌入写入更新，然后可以在查询时检索。
